### 🔧 Проекты

<table>
<tr>
<td width="50%" valign="top">

**[dorm-vpn-bypass](https://github.com/Rypleshhh/dorm-vpn-bypass)**

Селективная маршрутизация трафика через VLESS+Reality для обхода DPI-блокировки UDP на уровне роутера (OpenWrt).

- Разделение TCP/UDP на независимые inbound/outbound в Xray
- Хендшейк снижен с ~0.43 с до ~0.11 с за счёт `mux.cool`
- Автообновление доменных списков через nftables + dnsmasq

`OpenWrt` `Xray-core` `nftables` `Bash`

</td>
<td width="50%" valign="top">

**[sberazs_bot](https://github.com/Rypleshhh/sberazs_bot)**

Telegram-бот мониторинга АЗС с распределённой архитектурой из двух серверов.

- Сервер за NAT сам инициирует связь, а не наоборот
- Скрапинг (Playwright) и бот (aiogram) разнесены по ролям
- Аутентификация по токену, health-check, защита от дублей

`Python` `aiogram` `Playwright` `Docker`
